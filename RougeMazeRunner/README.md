# 4410 Final Project
Final project for cse4410

Title:RougeMazeRunner

Description: Rouge MazeRunner is a 2D top-down maze game developed in Unity. The player's objective is to navigate through a preset maze and collect three randomly spawned keys. Once the player successfully collects all three keys, a door near the start of the maze unlocks, allowing them to exit and complete the round. To increase the challenge, each subsequent round shortens the time limit, requiring the player to move faster and more efficiently. The win condition is met when the player collects all the keys and reaches the unlocked door. If the countdown timer reaches zero before this is accomplished, the game displays a Game Over screen, indicating that the player has lost the round.
